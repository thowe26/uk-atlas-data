# Project: UK Data Atlas
We are building a historical data visualization dashboard using vanilla HTML, CSS, and JavaScript.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS**: CSS Grid for layout. No external frameworks.
- **JavaScript**: Vanilla ES6+. No build steps.
- **Charts**: Chart.js (loaded via CDN).

## Design Guidelines
- **Layout**: Dashboard style. Grid of 'cards'.
- **Thumbnails**:
  - Aspect Ratio: A4 Landscape (1.41:1).
  - Interaction: Static images (events disabled).
  - Style: Title overlaid on top-left (absolute position).
- **Interaction**:
  - Clicking a thumbnail opens a full-screen Modal.
  - Modal must have "World Events" toggle and "Hover" tooltips.

## Tone & Content
- Use British English for all text (e.g., "Labour", "Centre").
- Focus on clear, historical economic storytelling.
